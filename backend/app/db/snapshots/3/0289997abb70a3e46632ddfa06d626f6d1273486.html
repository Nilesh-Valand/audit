What’s the difference between ASP.NET and ASP.NET Core?

ASP.NET Core is a part of ASP.NET. It was called ASP.NET 5 earlier, but then it was changed to ASP.NET Core. As far as features and benefits are concerned, ASP.NET Core has a lot to offer than ASP.NET 4x. ASP.NET Core works on various systems like macOS, Windows, and Linux, whereas ASP.NET 4x is built only for Windows. So, now it depends upon you what type of application you would like to develop.
