Difference between Web Design and Web Development

• Web design is associated with the website's looks and feels, whereas web development is related to the website's functions.

• Photoshop, Illustrator, DreamWeaver, Sketch, and Adobe are major tools for web design. PHP, HTML, CSS, JavaScript, Python, Ruby, and jQuery are major languages of web development

• There are two main types of web design - UX and UI. There are three types of web development - Front-end, Back-end, and Full-stack.
